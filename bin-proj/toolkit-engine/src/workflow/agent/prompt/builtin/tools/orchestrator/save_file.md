把一段内容写成文件交付给用户。文件存到**用户启动 tke 时所在的当前目录（及其子目录）**——和其他 coding agent 一样，你的文件操作范围就是这棵目录树。参数 `filename`=相对文件名（如 `policy.md` 或 `docs/policy.md`，可含子目录、会自动建；不接受绝对路径或 `..` 跳出）；`content`=完整内容。用于"把 policy 存成 md""把读到的信息保存下来"等——通常先 explore 取回末页文字，你整理成 markdown 后用它落盘。**返回文件的完整绝对路径——务必把这个路径原样告诉用户**；没成功拿到路径前别说"已保存"。
