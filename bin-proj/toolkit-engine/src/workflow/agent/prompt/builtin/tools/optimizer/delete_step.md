删掉一个**无效操作步**（执行后页面结构没变、又没被随后断言确认 = 点了个不起作用的元素：点了没反应、重复点击、绕回又绕回）。
- step：要删的步号(1-based)，**必须是 intro 里「可删的无效操作步」列出的那些**。
- reason：为什么这步是没让页面变化的无效点击、删了安全（如"它后面没断言、紧接着又点了别的，说明这次点击没生效"）。
典型信号：trace 里一个**点击后没跟断言、下一步又是另一个点击**——前一个点击多半无效，可删。
注意：改变了页面/打开了新标签/导航过去的步是**承重步**，删了会让后续依赖该状态的步失效——系统会拒绝。
**断言（踩实校验）步也绝不能删**：它虽不改变页面，却是脚本回放时"走错页就立刻报错"的自检承重点，删了问题极难定位——系统同样会拒绝。
