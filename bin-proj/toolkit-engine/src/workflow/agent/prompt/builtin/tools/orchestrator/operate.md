在设备上完成一项**一般任务**（不是测试）：朝 `goal` 描述的目标自动操作设备（导航、点击、滚动、截图等），完成后返回结果——**末页可读文字 + 末页截图路径 + 简述**。不产生可回放脚本、不做验证。用它来干测试以外的事：进到某个页面把内容读出来、找到并截取某个元素、把 App 某页的信息取回来等。拿到返回的末页文字/截图后，你再决定怎么交付给用户（直接答复、或用 save_file 存成文件）。一次一个目标；目标要具体（"进入隐私政策页并停在那里"好过"看看 App"）。
任务是**读取长内容**（如整页 policy、一篇说明）时把 `read_full` 设为 true：到达目标后会**滚动逐屏收集全部文字**返回；只是截个图/找个元素就留 false（默认），免得乱滚走开。
