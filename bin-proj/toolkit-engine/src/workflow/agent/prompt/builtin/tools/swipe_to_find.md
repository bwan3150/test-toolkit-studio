滚动查找：朝某方向滚动页面，**直到目标文字出现**在可视区。这是找"在更下方、需要滚动才能看到的东西"的**首选**方式——比反复用 swipe_direction 盲滑一屏一屏找更高效、且生成的脚本**回放时能可靠地滚到同一位置**（固定距离的盲滑回放时受加载时机影响，常滚不到同一处，导致回放找不到目标）。

- target：要滚到的目标**可见文字**（页面上会出现的文字，如某个名称、标题、区块名、按钮或链接文字）。
- direction：滚动方向；目标在更下方就用 up（向上滑=看下方内容）。

用法：当你知道要找的东西（如某产品、某区块）但它还没出现在当前屏时，直接 `swipe_to_find(target="某段可见文字", direction="up")`，系统会滚动直到它出现；然后下一步再 click 它。找不到（滚到底仍没有）会报错，说明它不在这个方向/这个页面。
