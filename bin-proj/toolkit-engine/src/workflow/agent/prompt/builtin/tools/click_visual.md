视觉点击：仅在「元素列表里既没有对应的结构元素、也没有对应的 OCR 文字元素」时使用，且**必须先调用 request_screenshot 看过当前截图**。

用途：让你点击一个只能从截图里看出来、但页面结构和 OCR 都定位不到的目标（如纯图标、自绘控件）。

参数：
- region（优先）：目标在**截图像素坐标**下的外接框 `[x1, y1, x2, y2]`，尽量贴合目标本身（不要框进多余背景），框越准，换设备回放越稳。
- x, y：给不出 region 时，至少给目标中心的像素点；系统会在该点周围自动取一个方块作为模板。
- name：给该目标起的稳定语义名（落库并写进 .tks `{name}`，相同目标复用同名）。
- desc：可选，目标用途说明。

落库方式：该目标会被存成「结构通道为空、ocr 为空、只有截图模板」的元素，回放时靠图像模板匹配定位，因此能在不同分辨率的设备上复现。优先用普通 click（结构元素），其次才用本工具——它是最后的兜底。
