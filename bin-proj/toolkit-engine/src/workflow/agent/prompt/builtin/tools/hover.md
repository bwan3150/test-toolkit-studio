把鼠标**悬停**到一个元素上（**web 独有**），触发它的 hover 效果——最常见用途是**展开顶栏的下拉/悬停菜单**，然后下一步才能点到展开后的子项。

**什么时候用**：网页顶栏的导航项（如 `Products`、`Solutions`、`菜单`）很多是**鼠标悬停才展开**的下拉——直接 click 它往往不跳转、或点到的是同名的装饰元素，结果在多个页面间反复横跳。这时**先 hover 这个顶栏项**让下拉菜单展开，**下一轮再 click** 展开后出现的目标子项。

- 只需 element_id（要悬停的那个元素序号）。
- 悬停后系统会等下拉渲染稳定再继续；下一轮你就能在页面元素列表里看到展开出来的子项，点它即可。
