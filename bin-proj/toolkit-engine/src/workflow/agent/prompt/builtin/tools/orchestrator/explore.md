朝 `goal` 在设备上自动操作完成一件事——测试用例 或 一般任务都走它。始终产出可回放的 .tks 脚本（只记设备动作）+ log + 元素，并返回**末页可读文字 + 末页截图路径**（供答问/存文件/交付）。
- `make_test=true`：要产出**可回放、可验证的测试脚本**时——开每步自动断言 + 完成把关，之后可用 verify 校验稳定性。一般任务（只要把事做完/拿到结果）留 false（默认，更轻、脚本只有设备动作、不插断言）。
- `read_full=true`：任务是读**长内容**（整页 policy、一篇说明）——到达目标后滚动逐屏收集全文。截图/找元素留 false（默认，不乱滚走开）。
- `note`：可选的额外约束/提示（用户纠偏、已否定路径、需留意的细节）。
一次一个目标；目标要具体。要测下一件事就再次调用（上一件若没收尾会自动先收尾）。
