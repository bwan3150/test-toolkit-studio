朝 `goal` 在设备上自动操作完成一件事——测试用例 或 一般任务都走它。把过程录成可回放的 `.tks` **写进工作区当前目录**（`script_name` 命名、不给则按 goal 取名、目录内自动去重），元素打包进同名 `<name>.tklib` 元素包（与 .tks 两件套，拷到别的机器即可回放）；返回**脚本路径 + 末页可读文字 + 末页截图**（供答问/存文件/后续 replay）。
- **goal 只写"在设备上要到达/做的那一步"**（如『进入隐私政策页』），别把"读全文/整理/存 md"塞进 goal——全文自动随返回带回、存盘用 save_file。
- `make_test=true`：要**可回放、可验证的测试脚本**时——开每步自动断言 + 完成把关（脚本更适合之后 replay_tks/repair_tks）。一般任务留 false（默认，更轻、脚本只有设备动作）。
- `read_full=true`：读**长内容**（整页 policy 等）——驱动只导航到内容页，系统自动逐屏收集全文回给你；别让它滚着读。
- `note`：额外约束/提示（用户纠偏、已否定路径、需留意的细节）。
一次一个目标、要具体。一次对话可多次调用产出多个脚本（各自独立的工作区文件）。
