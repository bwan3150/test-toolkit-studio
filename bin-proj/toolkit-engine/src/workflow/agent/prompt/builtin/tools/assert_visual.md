看图视觉断言：和 assert 一样给脚本加**闭环校验**，但用于**看图才能认出的标志**——当该页的独特标志是图标/logo/无文字图块、结构与 OCR 元素列表里**没有**可断言的对象时，看截图直接框出它。不操作设备，只在脚本里留一个"必须满足"的检查点；回放靠**图像模板匹配**校验它在不在。

何时用：
- 想 assert 踩实当前页、但列表里挑不出该页独有的文字/结构元素（标志只是个图标、产品图、品牌 logo 等）。
- 这是 assert 的视觉兜底，定位优先级与 click 一致：能用列表元素 assert 就别用它；非看图不可才用。

字段（与 click_visual 对称）：
- **region**：标志在截图中的像素框 [x1,y1,x2,y2]（优先，越贴合越好）。
- **x / y**：无 region 时给标志中心点像素。
- **exist**：断言存在(true，默认)还是不存在(false)。

**重要判断**：如果你在当前页**既挑不出可断言的文字/结构元素、也找不到一个能看图框出的、足以证明"我到了预期那一页"的独特标志**——那往往不是"该页没法断言"，而是**你上一步很可能点错了元素 / 没真正导航过去**（点了个不跳转的同名项、悬停菜单没展开等）。这时**别硬框一个无关图块来凑数**，应当 back 回上一页、换一个更对的元素重试上一步。
