点击一个元素。

三个字段分工：
- **name**：这个**控件本身**的稳定语义名（它"是什么"，名词），会作为测试资产落库、回放定位用。
  - 好：`KonecHome应用图标`、`导航栏个人中心入口`、`设置页退出登录按钮`
  - 坏：`打开KonecHome应用`、`进入个人中心`（这些是动作，不是元素）
  - 同一控件在多轮里复用同一个 name。列表里标了「已知元素「X」」的，直接复用 name=X。
- **desc**：可留空——系统会在探索结束后据元素实际作用统一生成，无需在创建时猜测。
- **comment**：你这一步的思考（结合已做过的步骤，现在想做什么、为什么）。只用于展示和给后续步骤参考，不落库。
