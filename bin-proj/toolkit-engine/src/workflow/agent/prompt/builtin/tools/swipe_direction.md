从屏幕中心做一次定向滑动（滚动页面）。

**方向含义（最容易搞错，务必看清）**：
- direction=`up`（向上滑）→ 内容上移 → 看到页面**更下方**的内容（=往下翻页）。**要找页面下方的东西就用 up！**
- direction=`down`（向下滑）→ 看到页面**更上方**的内容（=往上翻 / 回顶部）。
- left / right 同理（横向）。

**幅度**用 amount（屏幕比例，免算像素）：`full`≈整屏、`half`≈半屏、`quarter`≈四分之一屏；默认 half。

**重要**：连续滑动后页面**一直没变化**，多半是①方向反了（想往下却用了 down），或②已到顶/到底。这时**换一个方向**试或换别的做法，别在同一方向反复滑。
