断言：校验某个元素在当前页面**存在**（或不存在）。这是给脚本加**闭环验证**的关键——不操作设备、不改变页面，只在脚本里留下一个"必须满足"的检查点，回放时若没真正到达该状态就会在此明确失败（而不是悄悄跑偏到错页面还继续往下点）。

何时用（很重要，光点击/滑动没有闭环）：
- **每到达一个关键中间页**：断言该页独有的标志元素存在（如进入产品分类页后断言分类标题、进入详情页后断言产品名/型号），确认这一步真的导航到位。
- **到达目标页/完成目标操作后**：断言只有真正达成目标才会出现的独特元素（如目标文档编号、SKU、成功提示）。
- 偶尔也可断言某元素**不存在**（exist=false），如确认弹层已关闭、登录入口已消失。

字段：
- **element_id / name**：要断言的元素序号 + 它的稳定语义名（名词，会落库并写进 `断言 [{name}, 存在]`）。挑该页**独有、稳定**的元素，别挑每页都有的通用控件。
- **exist**：断言存在(true，默认)还是不存在(false)。
- **comment**：你这一步为什么要在这里加这个校验。

注意：断言不前进流程，只是插一个检查点；别滥用，挑关键节点断言即可。
