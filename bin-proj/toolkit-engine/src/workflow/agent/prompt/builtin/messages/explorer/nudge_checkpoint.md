你刚点击/切换进入了新页面——先别急着继续往下操作。请先给这一步**踩实**一个校验：

1. 在当前页挑一个**该页独有、稳定**的标志元素，用 **assert** 断言它存在（页面标题、分类名、产品型号/编号、文档 SKU 等；别挑导航栏/页脚这种每页都有的通用控件）。
2. 如果该标志是图标/logo/无文字图块、元素列表里挑不出来 → 用 **assert_visual** 看截图框出它来断言。

**关键**：如果你发现这一页**根本找不到任何能证明"我确实到了预期那一页"的独特标志**（既没有可断言的文字/结构元素，也框不出一个有意义的视觉标志）——那通常**不是**这页没法断言，而是**你上一步很可能点错了元素、或那次点击没真正导航过去**（比如点了个不跳转的同名项、悬停菜单没展开、停在了中间层）。这时**不要硬凑一个无关元素来断言**，而应：**back 回上一页，换一个更对的元素重试上一步**。

踩实（或纠正上一步）之后，再继续下一个操作。
