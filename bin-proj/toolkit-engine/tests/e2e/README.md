# e2e(真机)测试

这里放**需要真实环境**(设备/[ai] 配置/网络)的端到端脚本,CI 跑不了,需要的时候手动跑。

| 脚本 | 干什么 | 跑法 |
|---|---|---|
| `smoke.sh` | 两件套回放冒烟:辅助驾驶开/关各跑一遍 | `./tests/e2e/smoke.sh path/to/case.tks [device]` |

约定:
- 前提不满足(缺 tke/缺设备/缺两件套)要**说清楚再退出**,不许假绿
- 新脚本先在"环境故意不满足"下跑一遍,确认报错路径工作(PITFALLS P-12 同款纪律)
- 测试分层见 ADR-0008:单测/无设备集成在 src 内,CLI 契约在 tests/cli.rs,真机在这里
