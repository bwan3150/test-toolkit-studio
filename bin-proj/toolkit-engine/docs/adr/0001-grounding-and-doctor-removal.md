# ADR-0001: 接地原则——删除医生 agent,修复重建为"自愈+断点续探+页面契约"

- **状态**: 生效
- **日期**: 2026-07-06
- **关联**: INV-1 / INV-3 / INV-6, commit 57ed54e7→1f6d49b1

## 背景
医生（多轮编辑 .tks 文本的 agent）迭代几十版始终不可靠：它编辑脚本文本,
却只看得到过期 trace——对看不见的设备做脑内手术。

## 决策
医生整体删除。多轮 agent 必须接地在它正在改变的状态上;不接地的任务拆成单次调用。
修复 = 定位级自愈（healer,单次,基于实时页面）+ 断点续探（explorer 从失败现场接管）+
页面契约（断言页面投票）。修复决策上移到编排官（对话层）,没有一键黑盒。

## 理由与代价
23/23 测试连跑三次稳,真机多轮迭代确认。代价:修复不再是"一个命令",要编排官多轮调度——
这是特性不是缺陷（用户可随时纠偏）。曾试过"代码 agent 式编辑脚本任意行",实践证明不接地必败。
