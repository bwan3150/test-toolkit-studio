# ADR-0004: 页面契约——pages 实体 + 断言页面指令按命中率投票

- **状态**: 生效
- **日期**: 2026-07-08（1e58b91a 定稿）
- **关联**: INV-6, ADR-0001

## 背景
起始/终点校验的演进：单词 marker→(登录登出案暴露猜错)→末页摘取→(单词无语义)→
desc+快照→(用户点破"备注是散装")→页面实体统一。

## 决策
元素包 pages 节存「页面」实体（desc + 特征文字集≤40 + 截图）;
`断言页面 ["起始页"/"完成页"]` 按命中率投票（≥60%）;探索 finalize 自动落页面+首尾插断言步。
校验 = 脚本自身的普通步骤,回放器真实执行。头注释标志降级为老脚本兜底。

## 理由与代价
判据来自真实页面,失败信息带 desc/命中率,人和 AI 都看得懂差在哪。
代价:特征文字随改版会老化——命中率投票（而非全等）就是为此留的余量。
