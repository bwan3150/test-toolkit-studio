# ADR-0003: 元素包两件套（foo.tks + foo.tklib）,彻底删除共享元素库

- **状态**: 生效
- **日期**: 2026-07-03
- **关联**: INV-7

## 背景
共享元素库让新脚本的写入污染旧脚本的定位依据,跨机器拷贝测试要带一堆散件。

## 决策
一个测试 = 两个文件,拷走即跑。tklib 是 zip 容器（meta+element.json+img/）,
运行期"解包→操作→回包"（像 docx）,下游对包无感知。全局 --element 参数删除。

## 理由与代价
自包含与隔离 > 复用。代价:同一元素在多个脚本里重复存——接受,定位宇宙独立更重要。
