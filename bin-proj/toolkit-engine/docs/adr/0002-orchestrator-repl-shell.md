# ADR-0002: 主 AI 形态 = 会对话的顶层 REPL 外壳（测试专精版 Claude Code）

- **状态**: 生效
- **日期**: 2026-06-26（形态拍板）→ 2026-06-30（工具颗粒化）
- **关联**: INV-3, commit 链 009c461c→62768626→d01ec0d2→57a897b5

## 背景
原来是"接到用例→固定线性流水线（探索→验证→修复→稳定）"。

## 决策
orchestrator 是最顶层长寿 REPL：能聊、连跑多条用例、随时插话。
固定流水线拆成颗粒化工具（explore/replay_tks/resume_explore/navigate/optimize_tks/文件工具）,
流水线降级为提示词建议。通用任务与测试是**同一套**驱动循环（唯一区别=要不要可回放校验）。

## 理由与代价
北极星是"测试领域专精的 Claude Code",不是过场机器。代价:非交互(app spawn/CI)需要
nudge/自动收尾护栏防空转,授权流按 opencode 三态设计。
