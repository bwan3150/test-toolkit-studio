## Q-8 (2026-08-13) skill 侧缺「不依赖元素库的等待」
`.tks` 的重试断言 `断言 [{元素}, 存在, 15s]` **需要元素库**,而 tke-ui-test skill 明令不建元素库
(ADR-0010:只做一次性检查,不产资产)。于是跨设备等下发只能让调用方 AI 自己写 shell 轮询
(`for i in $(seq ...); do tke -d X fetch | grep -q ...; done`)——已写进 SKILL.md 并实测可用,
但**护栏全靠提示词**:忘超时、忘判断命中、误用 `--interactive` 都会产生假结论(我自己第一版就
误用了 `--interactive`)。

ADR-0010 埋的坑那节写过:**护栏退化的出路是做成必须调用的子命令,不是把提示词写更长**。
阻塞:跨设备检查的可靠性。等用户 mac 实测一轮再定——若 AI 照提示词就能写对,可以不加。
